Global dataset build
--------------------

# 1. Scrape all leagues for matchweek
python scripts/Player_Scraper.py --season 2025-26 --matchweek 38 --all-leagues --csv data/raw/player_match_logs.csv --unmapped-out data/diagnostics/unmapped_stats.json --coverage-out data/diagnostics/stat_coverage_by_mw.json --delay 1.2

# 1b. Build positional context
python scripts/Build_Position_Context.py --input data/raw/player_match_logs.csv --output data/context/position_context_by_event.json --enrich-csv data/raw/player_match_logs.csv --season 2025-26 --delay 1.2

# 2. Add ages / DOBs
# Uses previous enriched CSV/cache so it does not refetch everyone.
python scripts/Add_Player_Ages.py --input data/raw/player_match_logs.csv --output data/processed/player_match_logs_with_ages.csv --cache cache/player_profile_cache.json --seed-from data/processed/player_match_logs_with_ages.csv --delay 1.2

# 3. Collapse to season totals
python scripts/Player_Collapse.py --input data/processed/player_match_logs_with_ages.csv --output data/processed/player_season_totals.csv

# 4. Arbitrate positions
python scripts/Position_Arbitrator.py --input data/processed/player_season_totals.csv --output data/processed/player_season_totals_arbitrated.csv --season 2025-26 --min-minutes 700 --position-context data/context/position_context_by_event.json

# 5. Classify roles
python scripts/Player_Role_Classifier.py --input data/processed/player_season_totals_arbitrated.csv --output data/processed/player_roles.csv --season 2025-26 --min-minutes 700

Player-specific build
---------------------

# Edit these per card
$PLAYER_ID=830659
$SEASON="2025-26"

# 6. Similar players, all leagues
python scripts/Find_Similar_Players.py --input data/processed/player_season_totals_arbitrated.csv --roles-input data/processed/player_roles.csv --player-id $PLAYER_ID --season $SEASON --top 30 --min-minutes 1350 --format both --output-prefix cards/similarities/similar_${PLAYER_ID}_all_leagues

# 7. Fetch player event/card data
# IMPORTANT: output should live in cards/event_data, not project root.
python scripts/Fetch_Player_Event_Data.py --player-id $PLAYER_ID --season $SEASON --delay 1.2 --out cards/event_data

# 7b. Optional action scraping
# Player-specific only. Do not run this for the whole dataset.
python scripts/Player_Action_Scraper.py --player-id $PLAYER_ID --season $SEASON --refresh-cache --schema-debug

# 8. Build visual-only heatmap
# IMPORTANT: output should live in cards/heatmaps, not project root.
python scripts/Build_Player_Season_Heatmap.py --player-id $PLAYER_ID --season $SEASON --match-log data/raw/player_match_logs.csv --out-dir cards/heatmaps --delay 1.2 --format both

# 9. Build final player card
# Pass explicit paths so the builder does not accidentally auto-load old root files.
python scripts/Player_Card_Builder.py --player-id $PLAYER_ID --season $SEASON --season-totals data/processed/player_season_totals_arbitrated.csv --roles data/processed/player_roles.csv --similarity cards/similarities/similar_${PLAYER_ID}_all_leagues.json --search-dir cards --out cards/output/player_card_${PLAYER_ID}_${SEASON}.json --min-minutes 1350

Player Finder
---------------------
# 10. Find players within parameters
How it works:
Every filter is an optional CLI flag — use as many or as few as you want. There are three filter types:
Categorical — substring match (case-insensitive) unless noted:
--name, --team, --league, --nationality
--position   (exact: CB, ST, CM, GK, LB, RB, DM, AM, SS, LW, RW, …)
--role_group, --lane, --preferred_foot, --season_position_zone
Numeric — every stat gets a _min and _max variant:
--goals_min 10 --xg_per90_min 0.5 --minutes_played_min 900
--aerial_win_pct_min 60 --pass_accuracy_pct_max 70
--gk_goals_prevented_min 2 ...and ~140 more stats
Output controls:
--sort goals --desc          # rank results
--limit 20                   # top N only
--show player_name,team,goals,xg,xa   # custom columns (or 'all')
--list_columns               # print every available column name
--no_truncate                # disable column width capping
When using percentage stats like --aerial_win_pct_min or --dribble_success_pct_min, pair them with a volume filter (e.g. --aerial_duels_total_min 30) to avoid small-sample noise.
--key_passes_per90_min 5 returned no results because no player in this dataset quite reaches that threshold — the column is definitely there and queryable at a lower bound.
Run python Player_Finder.py --list_columns to see all 251 column names you can filter or display.

Housekeeping rules
------------------

Root folder should contain scripts/folders only, not generated player files.

Move existing files as follows:

*_PLAYERID_2025-26.json that are event-data files
→ cards/event_data/

*_heatmap_position.json
→ cards/heatmaps/

*_heatmap_position_cells.csv
→ cards/heatmaps/

*_actions_raw.json
*_actions_summary.json
*_actions_flat.csv
→ cards/actions/

similar_*.json
similar_*.csv
→ cards/similarities/

player_card_*.json
→ cards/output/

player_profile_cache.json
→ cache/

.heatmap_cache/
→ cache/.heatmap_cache/


Suggested cleanup commands
--------------------------

# Create folders
mkdir cards\event_data -Force
mkdir cards\heatmaps -Force
mkdir cards\actions -Force
mkdir cards\similarities -Force
mkdir cards\output -Force
mkdir cache -Force

# Move generated event data
Move-Item "*_2025-26.json" cards\event_data -ErrorAction SilentlyContinue

# Move heatmaps back out of event_data if caught by the broad rule above
Move-Item "cards\event_data\*_heatmap_position.json" cards\heatmaps -ErrorAction SilentlyContinue
Move-Item "*_heatmap_position.json" cards\heatmaps -ErrorAction SilentlyContinue
Move-Item "*_heatmap_position_cells.csv" cards\heatmaps -ErrorAction SilentlyContinue

# Move similarities
Move-Item "similar_*.json" cards\similarities -ErrorAction SilentlyContinue
Move-Item "similar_*.csv" cards\similarities -ErrorAction SilentlyContinue

# Move final cards
Move-Item "player_card_*.json" cards\output -ErrorAction SilentlyContinue

# Move caches
Move-Item "player_profile_cache.json" cache -ErrorAction SilentlyContinue
Move-Item ".heatmap_cache" cache -ErrorAction SilentlyContinue


Important notes
---------------

1. Similarity should usually be all-league:
   do not pass --league unless you intentionally want same-league comps.

2. Heatmap is visual/action-density only:
   position truth comes from Position_Arbitrator.py.

3. Action scraper is optional and player-specific:
   it belongs with event data and heatmaps, not the global dataset build.

4. Player_Card_Builder should be given explicit paths or a clean --search-dir:
   this avoids accidentally using old files from the root folder.
